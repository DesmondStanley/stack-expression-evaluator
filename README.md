# Stack-Based Mathematical Expression Evaluator

A Python program that reads mathematical expressions from `input.txt`, evaluates each one using a stack, and writes the results to `output.txt` in the same layout.

## Files

| File | Purpose |
|---|---|
| `expression_evaluator.py` | The program (Stack class, evaluator, file handling) |
| `input.txt` | Sample input used for testing |
| `output.txt` | Output generated by the program |
| `README.md` | This file |

## Requirements

- Python 3.8 or newer
- No external libraries (standard library only), so nothing needs to be installed with `pip`

## How to Run

**In PyCharm**

1. Open the project folder (File > Open).
2. Make sure a Python 3 interpreter is selected (Settings > Project > Python Interpreter).
3. Right-click `expression_evaluator.py` and choose **Run**.

**From a terminal**

```bash
python expression_evaluator.py
```

(Use `python3` on macOS/Linux if `python` is not found.)

The program looks for `input.txt` in the same folder as the script and creates `output.txt` there.

## Input File Format

- One mathematical expression per line.
- Expressions are separated by a separator line, such as `_ _ _ _ _` (made only of `_`, `-`, `=`, `*`, `#` and spaces).
- Blank lines are allowed and are kept in the output.

Example `input.txt`:

```
3 + 5 * 2
_ _ _ _ _
( 8 / 4 ) + 7 * 2
_ _ _ _ _
10 - ( 2 + 3 ) * 4
```

## Output File Format

Each expression is replaced by its result. Separator lines are copied unchanged.

Example `output.txt` for the input above:

```
13
_ _ _ _ _
16
_ _ _ _ _
-10
```

Note: the assignment sheet shows `17` for `( 8 / 4 ) + 7 * 2`, but the correct value is 16 (8 / 4 = 2, 7 * 2 = 14, 2 + 14 = 16).

## How It Works

1. A `Stack` class provides `push`, `pop`, `peek`, `is_empty` and `size`.
2. `tokenize` splits an expression into numbers, operators and parentheses, and detects unary minus.
3. `evaluate_expression` uses two stacks: a **value stack** for numbers and a **operator stack** for pending operators and parentheses. Operator precedence is `*` and `/` above `+` and `-`, and parentheses override precedence.
4. `process_file` reads `input.txt` line by line, evaluates each expression, and writes the results to `output.txt`.

## Supported Features

- Operators: `+`, `-`, `*`, `/`
- Parentheses, including nested parentheses
- Decimal numbers (for example `2.5 * 4`)
- Negative numbers (for example `-3 + 4` and `2 * -4`)
- Whole-number results are shown without a decimal point (`13`, not `13.0`)

## Error Handling

The program does not stop on a bad expression. It writes an error message on that line and continues:

| Problem | Output |
|---|---|
| Division by zero | `Error: Division by zero` |
| Missing or extra parenthesis | `Error: Mismatched parentheses` |
| Unsupported character | `Error: Invalid character 'x'` |
| Incomplete expression (for example `3 +`) | `Error: Invalid expression` |

If `input.txt` is missing, the program prints a message and exits.

## Assumptions and Limitations

- Each expression must be on a single line.
- Only the four basic operators and parentheses are supported (no exponents, functions or variables).
- Decimal results may show small floating-point rounding differences; results are rounded to 10 decimal places.
- A separator line must contain at least three separator symbols and no digits.
- Input and output files must be in the same folder as the script.
